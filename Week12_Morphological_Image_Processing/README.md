# 📝 [Week 12] 형태학적 영상 처리 (Morphological Image Processing)

## 1. 실습 개요

형태학(Morphology)은 영상 속 물체의 형태를 집합으로 보고, 작은 패턴인 **구조 요소(Structuring Element)**를 이동시키며 경계·연결·구멍·골격을 분석하는 기법입니다. 특히 이진 영상에서 다음 문제를 해결할 때 유용합니다.

- 작은 점 잡음 제거
- 끊어진 선 연결
- 붙어 있는 객체 분리
- 내부 구멍 채우기
- 경계 추출
- 객체를 한 화소 두께의 골격으로 축약

### 핵심 키워드

| 개념 | 역할 |
| --- | --- |
| **Structuring Element** | 어떤 이웃 모양을 검사할지 정의하는 작은 탐침 |
| **Erosion / Dilation** | 전경을 축소하거나 확장하는 기본 형태학 연산 |
| **Opening / Closing** | 작은 잡음 제거 또는 틈·구멍 연결을 위한 복합 연산 |
| **Morphological Gradient** | 팽창과 침식의 차이로 경계 띠를 추출 |
| **Skeletonization** | 연결성과 대략적인 모양을 유지하면서 한 화소 두께로 축약 |
| **Zhang-Suen** | 8-이웃 연결성을 보존하는 반복 세선화 알고리즘 |

## 2. 수학적 원리

### 2.1 이진 영상을 집합으로 표현하기

전경 화소의 좌표 집합을 $A$, 주변에서 검사할 작은 좌표 패턴인 구조 요소를 $B$라고 합니다.

#### 이동 (Translation)

점 $w=(u,v)$만큼 집합을 이동하면 다음과 같습니다.

$$
A_w=\{(a,b)+(u,v):(a,b)\in A\}
$$

#### 반사 (Reflection)

구조 요소를 원점 대칭시키면 다음과 같습니다.

$$
\hat{B}=\{-b:b\in B\}
$$

구조 요소의 모양과 크기가 결과를 결정합니다. 4-이웃 십자형은 상하좌우 연결에 반응하고, $3\times3$ 사각형은 대각선까지 포함한 영역에 반응합니다.

### 2.2 침식 (Erosion)

구조 요소가 전경 안에 완전히 포함되는 위치만 남깁니다.

$$
A\ominus B=\{w:B_w\subseteq A\}
$$

침식의 효과는 다음과 같습니다.

- 전경 객체가 얇아집니다.
- 작은 전경 잡음이 제거됩니다.
- 가는 연결이 끊어집니다.
- 붙은 객체가 분리될 수 있습니다.

### 2.3 팽창 (Dilation)

구조 요소가 전경과 하나라도 만나는 위치를 전경으로 만듭니다.

$$
A\oplus B=\bigcup_{b\in B}A_b
$$

팽창의 효과는 다음과 같습니다.

- 전경 객체가 두꺼워집니다.
- 작은 구멍이 줄어듭니다.
- 끊어진 선이나 가까운 객체가 연결됩니다.

> 전경을 흰색 255로 볼지 검정 0으로 볼지에 따라 코드의 조건식은 달라지지만 수학적 연산은 바뀌지 않습니다. 단지 전경의 표현이 반전됩니다.
> 

### 2.4 열림과 닫힘

#### 열림 (Opening)

침식 후 팽창합니다.

$$
A\circ B=(A\ominus B)\oplus B
$$

- 작은 전경 잡음 제거
- 돌출부 제거
- 좁은 연결 절단
- 큰 객체의 전체 형상은 대체로 유지

#### 닫힘 (Closing)

팽창 후 침식합니다.

$$
A\bullet B=(A\oplus B)\ominus B
$$

- 작은 구멍 채움
- 짧게 끊어진 부분 연결
- 오목한 경계 완화

두 연산은 순서가 반대이므로 결과도 다릅니다. 먼저 “잡음을 지울 것인가”와 “틈을 메울 것인가”를 판단해야 합니다.

### 2.5 형태학적 경계와 기울기

내부 경계는 원본에서 침식 결과를 뺍니다.

$$
\partial_{\mathrm{in}}A=A-(A\ominus B)
$$

외부 경계는 팽창 결과에서 원본을 뺍니다.

$$
\partial_{\mathrm{out}}A=(A\oplus B)-A
$$

형태학적 기울기는 팽창과 침식의 차이입니다.

$$
G(A)=(A\oplus B)-(A\ominus B)
$$

팽창 결과와 침식 결과의 차이는 객체 경계 주변의 띠를 남깁니다.

### 2.6 골격화 (Skeletonization)

골격화는 객체의 연결성과 대략적인 모양을 보존하면서 한 화소 두께의 선으로 줄이는 과정입니다. OCR의 획 분석, 지문 융선 분석, 도로·혈관 중심선 추출에 사용됩니다.

실습은 **Zhang-Suen 세선화 알고리즘**을 사용합니다. 경계 화소를 무조건 제거하면 선이 끊어질 수 있으므로 각 화소의 8-이웃 구조를 검사해 연결성을 해치지 않는 화소만 반복 삭제합니다.

## 3. 핵심 구현 로직

### 3.1 4-이웃 침식

실습 코드에서 전경은 255입니다. 중심이 전경이어도 상하좌우 중 하나가 배경이면 제거합니다.

```cpp
if (Img[i * W + j] == 255) {
    bool allForeground =
        Img[(i - 1) * W + j] == 255 &&
        Img[(i + 1) * W + j] == 255 &&
        Img[i * W + j - 1] == 255 &&
        Img[i * W + j + 1] == 255;

    Out[i * W + j] = allForeground ? 255 : 0;
} else {
    Out[i * W + j] = 0;
}
```

이는 십자형 구조 요소가 객체 내부에 완전히 들어가는지 검사하는 것과 같습니다.

### 3.2 4-이웃 팽창

중심이 배경이어도 상하좌우 중 하나가 전경이면 전경으로 바꿉니다.

```cpp
if (Img[i * W + j] == 0) {
    bool allBackground =
        Img[(i - 1) * W + j] == 0 &&
        Img[(i + 1) * W + j] == 0 &&
        Img[i * W + j - 1] == 0 &&
        Img[i * W + j + 1] == 0;

    Out[i * W + j] = allBackground ? 0 : 255;
} else {
    Out[i * W + j] = 255;
}
```

### 3.3 반복 팽창·침식

실습 파이프라인은 팽창 3회 후 침식 3회를 수행합니다.

```cpp
Dilation(Image, Output, W, H);
Dilation(Output, Image, W, H);
Dilation(Image, Output, W, H);

Erosion(Output, Image, W, H);
Erosion(Image, Output, W, H);
Erosion(Output, Image, W, H);
```

같은 구조 요소의 반복 적용은 더 큰 구조 요소를 한 번 적용한 것과 유사한 효과를 냅니다. 순서상 강한 닫힘에 해당하며 문자 획의 끊어진 부분과 구멍을 먼저 연결합니다.

### 3.4 Zhang-Suen 세선화의 삭제 조건

중심 화소 $P_1$ 주변을 시계 방향으로 $P_2\sim P_9$라고 정의합니다.

- $N(P_1)$: 8-이웃 전경 화소 수
- $S(P_1)$: 이웃을 한 바퀴 돌 때 배경→전경 전이 횟수

두 단계에 공통으로 적용되는 조건은 다음과 같습니다.

$$
2\le N(P_1)\le 6, \qquad S(P_1)=1
$$

$S(P_1)=1$은 주변 전경이 하나의 연결 덩어리라는 의미입니다. 한 반복은 서로 다른 방향 조건을 갖는 두 단계로 이루어집니다. 삭제 대상은 먼저 모두 표시한 뒤 한꺼번에 제거해야 순회 순서에 따른 결과 차이를 막을 수 있습니다.

전체 닫힘·세선화 코드는 `01_Closing_And_Thinning/src.cpp`에 있습니다.

### 3.5 끝점과 분기점 추출

세선화된 검정 선 주변에서 흑→백 또는 백→흑 전이 횟수를 세어 구조적 특징을 찾습니다.

- 전이 횟수 1: 끝점 후보
- 전이 횟수 3 이상: 분기점 후보

실습의 `FeatureExtractThinImage`는 후보 화소를 회색값 128로 표시합니다. 전체 코드는 `02_Feature_Extraction/src.cpp`에 있습니다.

## 6. AI/딥러닝과의 연결점

### 세그멘테이션 마스크 후처리

신경망이 출력한 마스크에는 작은 점, 구멍, 끊어진 경계가 흔히 생깁니다. 열림으로 작은 오검출을 제거하고 닫힘으로 내부 구멍을 메우는 방법은 현재도 널리 사용됩니다.

### 객체 분리와 계수

침식, 거리 변환, watershed를 조합하면 서로 붙은 세포나 동전을 분리할 수 있습니다. 의료영상의 세포 계수와 산업 검사에 직접 연결됩니다.

### Skeleton과 그래프 표현

혈관·도로·신경 섬유를 골격화하면 중심선을 그래프로 바꿀 수 있습니다. 끝점, 분기점, 길이, 곡률을 특징으로 사용하거나 Graph Neural Network의 입력으로 활용할 수 있습니다.

> **핵심 정리:** 형태학은 밝기값 자체보다 객체의 공간적 모양과 연결 관계를 다룹니다. 구조 요소는 “어떤 모양을 찾고 보존할 것인가”를 정의하는 작은 탐침입니다.
>
