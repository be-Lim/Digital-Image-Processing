# 📝 [Week 11] 컬러 영상 처리와 색 기반 분할 (Color Processing & Color-based Segmentation)

## 1. 실습 개요

컬러 영상 처리는 색 공간의 각 성분을 변환하거나 공간 필터를 적용해 정보를 강조·복원·분할하는 과정입니다. 이번 주차에서는 다음의 일관된 흐름을 학습하고 C++로 직접 구현합니다.

> **색 표현 선택 → 색 변환 → 관심 색 분리 → 공간적 후처리 → 객체 영역 결정**
> 

그레이 영상에 인공 색을 부여하는 **의사 컬러 처리**, 특정 색만 남기는 **컬러 슬라이싱**, 밝기·색 균형 보정, 컬러 영상의 평활화와 샤프닝, **YCbCr 기반 색 분할**이 모두 이 흐름에 속합니다. 실습 코드는 빨간 계열 과일을 분할하고, 피부색 후보를 연결요소 단위로 묶어 가장 큰 영역에 얼굴 바운딩 박스를 그립니다.

### 핵심 키워드

| 개념 | 역할 |
| --- | --- |
| **Pseudocolor** | 단일 밝기값을 사람이 구분하기 쉬운 색으로 변환 |
| **Color Transformation** | 입력 색 성분 벡터를 새로운 색 공간 또는 출력 성분으로 변환 |
| **Color Slicing / Masking** | 목표 색과 가까운 화소 또는 지정 범위의 화소만 보존 |
| **YCbCr** | 밝기 Y와 색차 Cb·Cr를 분리하여 조명 변화의 영향을 줄임 |
| **Blob Labeling** | 연결된 전경 화소를 하나의 객체 단위로 묶음 |
| **Bounding Box** | 선택된 객체의 최소·최대 좌표로 사각형 영역 표시 |

## 2. 핵심 이론 및 수학적 원리

### 2.1 의사 컬러 처리 (Pseudocolor)

의사 컬러는 단일 밝기값을 색으로 바꾸어 작은 밝기 차이를 사람이 쉽게 구분하도록 만드는 기법입니다.

#### Intensity Slicing

밝기 구간을 여러 영역으로 나누고 각 구간에 고정된 색을 대응시킵니다.

$$
f(x,y) \in [L_k,L_{k+1}) \Rightarrow C_k
$$

열영상, 의료영상, 지형 고도처럼 값의 범위를 빠르게 구분할 때 유용합니다. 다만 구간 경계가 불연속이므로 임계값 부근에서 색이 급격히 바뀝니다.

#### Intensity-to-Color Transformation

밝기값 $r$을 R, G, B 각각의 연속 함수에 통과시킵니다.

$$
R=T_R(r), \qquad G=T_G(r), \qquad B=T_B(r)
$$

구간별 고정 색 지정과 달리 부드러운 컬러맵을 만들 수 있습니다.

### 2.2 컬러 변환의 일반식

입력 화소를 $n$개의 성분 벡터 $\mathbf{r}=[r_1,\ldots,r_n]$로 나타내면 출력은 다음과 같습니다.

$$
s_i=T_i(r_1,r_2,\ldots,r_n), \qquad i=1,2,\ldots,n
$$

RGB에서는 세 채널이 함께 결과를 결정하지만, HSI에서는 명도 $I$만 독립적으로 처리할 수 있습니다.

### 2.3 보색 변환과 컬러 슬라이싱

정규화 RGB의 보색은 $1-R$, $1-G$, $1-B$로 표현할 수 있으며 관심 물체를 시각적으로 강조할 때 사용합니다. 컬러 슬라이싱은 목표 색 벡터 $\mathbf{a}$ 주변의 화소만 남깁니다.

#### 구형 영역 기준

$$
D(\mathbf{z},\mathbf{a})=\|\mathbf{z}-\mathbf{a}\|_2
$$

$$
D(\mathbf{z},\mathbf{a})\le D_0 \Rightarrow \text{관심 화소}
$$

색 거리를 자연스럽게 반영하지만 제곱·제곱근 계산이 필요합니다.

#### 직육면체 영역 기준

$$
R_l<R<R_h, \qquad G_l<G<G_h, \qquad B_l<B<B_h
$$

각 채널을 독립적으로 검사하므로 빠르지만 색 공간의 축 방향과 임계값에 민감합니다.

### 2.4 명조·색 보정

- **Tone correction:** 감마 변환 또는 구간별 선형 변환으로 밝기 범위를 조정합니다.
- **Color balancing:** 광원이나 카메라 때문에 특정 채널이 강해진 현상을 채널별 이득으로 보정합니다.
- **Histogram processing:** RGB 채널을 각각 평활화하면 색이 틀어질 수 있으므로 HSI의 $I$ 또는 YCbCr의 $Y$에 적용하는 편이 안전합니다.

### 2.5 컬러 평활화와 샤프닝

RGB 평균 필터는 각 채널에 동일한 공간 마스크를 적용합니다.

$$
\bar{R}(x,y)=\frac{1}{mn}\sum_{(s,t)\in S_{xy}}R(s,t)
$$

$G$, $B$도 같은 방식입니다. 라플라시안 샤프닝 역시 채널별로 적용할 수 있지만 색 잡음까지 강조할 수 있습니다. HSI의 $I$ 또는 YCbCr의 $Y$에만 적용하면 색상 보존에 유리합니다.

### 2.6 색 기반 분할

분할은 화소를 객체와 배경으로 나누는 연산입니다. RGB 임계값은 조명 변화에 민감하지만 YCbCr는 밝기 $Y$와 색차 $Cb$, $Cr$가 분리되어 피부색이나 특정 색을 찾기 쉽습니다.

1. RGB를 YCbCr로 변환합니다.
2. Cb·Cr 범위로 이진 마스크를 만듭니다.
3. 연결요소 라벨링으로 연결된 화소를 객체 단위로 묶습니다.
4. 가장 큰 블롭을 선택합니다.
5. 최소·최대 좌표로 바운딩 박스를 그립니다.

## 3. 핵심 구현 로직

### 3.1 RGB → YCbCr 변환

`RGB2YCbCr` 함수로 변환합니다. 24비트 BMP 배열은 메모리에 **B, G, R 순서**로 저장된다는 점에 주의합니다.

$$
\begin{aligned}
Y  &= 0.299R+0.587G+0.114B \\
Cb &= -0.16874R-0.3313G+0.5B+128 \\
Cr &= 0.5R-0.4187G-0.0813B+128
\end{aligned}
$$

```cpp
Y[i * W + j] = (BYTE)(
    0.299 * Img[i * W * 3 + j * 3 + 2] +
    0.587 * Img[i * W * 3 + j * 3 + 1] +
    0.114 * Img[i * W * 3 + j * 3]);

Cb[i * W + j] = (BYTE)(
   -0.16874 * Img[i * W * 3 + j * 3 + 2] -
    0.3313  * Img[i * W * 3 + j * 3 + 1] +
    0.5     * Img[i * W * 3 + j * 3] + 128.0);

Cr[i * W + j] = (BYTE)(
    0.5    * Img[i * W * 3 + j * 3 + 2] -
    0.4187 * Img[i * W * 3 + j * 3 + 1] -
    0.0813 * Img[i * W * 3 + j * 3] + 128.0);
```

### 3.2 빨간색 마스킹

소스에는 RGB 채널을 직접 비교하는 `Red_Masking_RGB`와 YCbCr 색차를 이용하는 `Red_Masking_YCbCr`가 함께 있습니다. 최종 실습에서는 다음의 경험적 YCbCr 조건을 만족하는 화소만 원본 색으로 유지합니다.

```cpp
if (Cb[i * W + j] < 140 && Cr[i * W + j] > 190) {
    // 원본 BGR 화소 유지
} else {
    // 검정으로 제거
}
```

$Cr$가 크다는 것은 빨간 성분이 밝기 기준보다 강하다는 뜻입니다. $Cb$ 상한을 함께 사용해 파란 계열을 억제합니다. 전체 코드는 `01_Red_Color_Segmentation/src.cpp`에 있습니다.

### 3.3 피부색 후보 마스킹

`Face_Masking_YCbCr` 함수의 얼굴 검출 실습은 다음 범위를 사용합니다.

```cpp
if ((Cb[idx] > 95 && Cb[idx] < 125) &&
    (Cr[idx] > 135 && Cr[idx] < 205)) {
    // 피부색 후보 유지
} else {
    // 배경 제거
}
```

이 값은 특정 영상과 조명에서 경험적으로 정한 임계값입니다. 카메라, 피부색, 화이트밸런스, 조명이 달라지면 범위를 다시 조정해야 합니다.

### 3.4 Grassfire 방식 연결요소 라벨링

`m_BlobColoring`은 아직 방문하지 않은 전경 화소를 만나면 스택 기반 깊이 우선 탐색을 시작합니다.

> 새 전경 화소 발견 → 새 라벨 부여 → 8-이웃 전경 화소를 스택에 저장 → 연결 화소가 없을 때까지 반복 → 블롭 면적 기록
> 

라벨링 후 가장 면적이 큰 블롭만 남깁니다. 이는 얼굴 피부 영역이 배경의 작은 오검출보다 클 것이라는 가정을 사용합니다.

### 3.5 바운딩 박스

선택된 블롭의 전경 화소를 위·아래·왼쪽·오른쪽에서 탐색해 다음 좌표를 구합니다.

$$
x_{\min},\ y_{\min},\ x_{\max},\ y_{\max}
$$

마스크가 아닌 원본 컬러 영상 위에 빨간 사각형을 그려 결과를 쉽게 해석할 수 있게 합니다. 전체 코드는 `02_Face_Detection/src.cpp`에 있습니다.

## 5. 트러블슈팅 및 공학적 고찰

- 고정 임계값은 조명, 화이트밸런스, 카메라, 피부색 변화에 약합니다. 영상 통계에 따라 적응형 범위를 정하면 강건성을 높일 수 있습니다.
- 형태학적 열림·닫힘을 적용하면 마스크의 작은 잡음과 내부 구멍을 정리할 수 있습니다.
- 가장 큰 블롭 하나만 고르는 대신 면적, 종횡비, 위치 조건을 함께 사용하면 오검출을 줄일 수 있습니다.
- `BlobArea[1000]`처럼 최대 객체 수가 고정된 구현은 객체 수가 많을 때 제한이 됩니다.
- BMP는 행 크기가 4바이트 배수가 되도록 패딩될 수 있으므로 일반적인 영상 크기를 지원하려면 stride를 계산해야 합니다.

## 6. AI/딥러닝과의 연결점

### 전통적 분할에서 학습 기반 분할로

색 임계값은 규칙이 명확하고 빠르지만 환경 변화에 약합니다. 현대의 semantic segmentation은 CNN이나 Transformer가 색뿐 아니라 모양, 질감, 문맥을 함께 학습해 화소별 클래스를 예측합니다. 그래도 색 공간 변환과 마스크 후처리는 입력 전처리와 결과 정제에 계속 사용됩니다.

### 얼굴 검출과 얼굴 인식의 차이

이번 실습은 피부색으로 얼굴이 있을 법한 **위치**를 찾는 검출입니다. 누구의 얼굴인지 판단하는 얼굴 인식은 검출된 얼굴에서 특징 벡터(embedding)를 추출하고 등록 템플릿과 유사도를 비교해야 합니다.

> **핵심 정리:** 색 공간은 단순한 표현 방식이 아니라, 분리하려는 정보가 축에 잘 드러나도록 문제를 다시 표현하는 도구입니다.
>
